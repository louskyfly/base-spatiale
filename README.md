# Base spatiale

Jeu de survie et construction en pixel art pour iPad, jouable au doigt.

▶ Jouer : https://louskyfly.github.io/base-spatiale/

- Un petit robot pilote, vu du dessus, perdu sur une planète pixelisée
- Mine du minerai, des cristaux, de la glace et fouille les épaves
- Construis ta base : panneaux solaires, batteries, foreuses, générateurs O₂, serres, murs, tourelles, radars, atelier
- La nuit, des créatures attaquent (et une reine toutes les 3 nuits)
- But : réparer la fusée pour rentrer
